# 手機首次設定

所有需要本人操作的正式驗收項目，統一填寫 [本人操作驗收清單](USER_ACCEPTANCE_CHECKLIST.md)；本頁為首次設定流程。

1. 在具有 Sites 能力的 ChatGPT 帳號完成建立與個人插件授權。保存回傳的**自己的 Site URL**。
2. 用 Android Chrome 開啟該 URL，使用同一 ChatGPT 帳號登入。不是安裝 SmallGreen 官網，也不是把共用 PWA 指向你的資料。
3. Chrome 選單選「安裝應用程式」或「新增至主畫面」。實際名稱依裝置版本而異；看不到時記錄瀏覽器／版本，不宣稱安裝通過。
4. 從桌面重開、返回、重新整理；建立合成紀錄，關閉後再打開核對。登出後應要求重新登入。
5. 「照片與備份」選照片或相機（是否提供相機由系統檔案選擇器決定），同意權限後上傳到自己的 Site。
6. 回到 ChatGPT，選個人 PetMCP 插件，請它「讀取最新附件，列出原始值、單位與不確定處供我核對」。確認後才寫入。
7. 另用 ChatGPT 原生 Voice 嘗試同樣工具；若當下 Voice 不支援插件，標記 blocked。PWA 不包含 Live iframe，也不承諾把麥克風無縫接到聊天。

離線只顯示離線提示，不快取健康資料。更新後重開；安裝、返回、更新、照片權限及登入保持必須在實機各自驗收。
